# 0094 한판 Windows판은 tenai.kr의 보안키가 있어야 켜지고, 보안키가 없는 동안 AI를 막는다

## 맥락

한판은 공개 저장소에서 누구나 받아 쓰는 오피스다. 사용자(저장소 주인)는 2026-11-04에 Windows 정식판을 tenai.kr 회원에게만 쓰게 하기로 정했다. 회원은 tenai.kr에서 보안키 파일(`hanpan.key`)을 받아 USB나 이 PC에 등록한다. 회원당 3개까지다. 기존 설치자에게는 14일 유예를 둔다. 설계는 `docs/superpowers/specs/2026-11-04-hanpan-vn-securitykey-design.md` 7장, 계획은 `docs/superpowers/plans/2026-11-05-hanpan-securitykey.md`에 있다. 서버(D)는 별도 설계다.

## 결정

- **보안키 확인은 서명 확인이다.** 보안키 파일과 활성화 정보는 tenai.kr이 Ed25519로 서명한다. 앱에는 `kid`별 공개키만 빌드 값으로 넣는다. 켤 때 서명, 기기 번호(해시), 키 번호와 회원 번호가 맞는지 인터넷 없이 확인한다.
- **기기 묶음은 서버가 서명한다.** 등록할 때 인터넷이 필요하다. 앱은 기기 번호의 SHA-256 해시만 보낸다. 활성화 정보를 다른 USB로 복사해도 기기 번호가 달라 켜지지 않는다.
- **폐기 확인은 온라인, 30일까지 오프라인을 허용한다.** 하루에 한 번 서명된 상태와 서버 시각을 받는다. 마지막으로 받은 서버 시각(또는 등록 시각)에서 30일이 지나면 이유를 따지지 않고 잠근다. PC 시계를 그보다 5분 넘게 되돌리면 잠근다.
- **유예는 빌드에 넣는 고정 날짜다.** 등록 정보가 전혀 없을 때만 [나중에 하기]가 있다. 등록한 USB가 빠지면 유예와 관계없이 잠근다.
- **AI 키는 두 겹으로 잠근다.** 등록하면 vault 키(무작위 32바이트)를 같은 곳에 둔다. AI 키는 vault로 AES-256-GCM 암호화한 뒤 운영체제 봉인(DPAPI)을 한 번 더 한다(`sealed:v2:`). 기존 `sealed:v1:` 값은 등록 직후와 다음 시작 때 v2로 바꾼다. USB가 없으면 v2 값은 열리지 않아 "키 없음"으로 읽힌다. 터미널의 `--reveal-ai-secrets`도 마찬가지다.
- **잠금 동안 AI와 바깥 창구를 막는다.** 잠그면 `@genoffice/ai-provider`의 프로세스 전체 잠금이 켜진다. 키 제공자 요청, 구독 프로그램 실행, 내 PC AI, 홈 검색의 재정렬이 거절되고, 진행 중인 요청은 [중지]처럼 끝난다. AI 포토·AI 일러스트 도우미도 같은 길로 막힌다. 앱 안 MCP 서버는 423으로, 제어 채널은 `app_unavailable`로 답한다. `ai-settings.json`과 홈 검색 키 쓰기도 거절한다. 창과 문서는 닫지 않고, 보이는 창마다 잠금 덮개를 띄운다.
- **Windows에서만 한다.** Mac·Linux는 빌드 값과 관계없이 지금처럼 켜진다.

## 택하지 않은 것

- **기기 묶음을 앱이 혼자 만들기.** 서버 없이 등록할 수 있지만, 활성화 정보를 위조하면 3개 제한이 무력해진다.
- **사람마다 "처음 켠 날부터 14일" 유예.** 기록 파일을 지우면 유예가 다시 시작된다.
- **셸 페이지 안의 잠금 덮개.** 탭이 셸 페이지 위에 그려져서 가려지지 않는다.
- **새 오류 종류 `locked`.** 덮개가 창을 가려 사람이 볼 일이 거의 없다. 기존 "연결 안 됨"(`not-connected`)을 쓴다.

## 결과

- 공개 저장소의 소스에서 확인 코드를 지우고 직접 빌드한 앱, 업데이트를 받지 않은 옛 버전, Mac·Linux판, 터미널 명령 `ieumoffice`와 `--headless-export`는 막지 못한다(스펙 7-10).
- PC 보관을 고르면 vault도 PC에 있어 두 번째 잠금의 이득이 없다. 등록 창의 경고가 이 점을 알린다.
- 서버가 30일 넘게 멈추면 모든 사용자가 잠긴다. 서버 감시로 관리한다.
- 켤 때 등록한 PC에서는 USB 목록을 PowerShell로 한 번 읽는다(1~2초). 등록하지 않은 PC에서는 아무 프로그램도 띄우지 않는다.
- 개발과 시험은 가짜 서버(`tools/securekey-dev-server.mjs`)와 테스트용 키 쌍으로 한다. 서명용 비밀키는 저장소에 넣지 않는다.
