# AI 도면

AI 도면은 간단한 3D 모형과 도면을 다루는 탭입니다. 받은 도면을 열어 치수를 확인하고, 작은 모형을 손으로 또는 AI에게 말로 만들고, 치수 도면을 한글이나 워드 문서에 넣을 수 있습니다. 도면은 .ttukcad 파일로 저장되고, 길이는 모두 mm 단위입니다.

## AI 도면 열기와 파일 열기

- 새 도면은 홈에서 **모든 앱**을 열고 **AI 도면**을 누릅니다. 탭은 **제목 없는 도면**으로 시작합니다.
- 파일은 **파일 › 열기…**(Ctrl+O)로 열거나 창에 끌어다 놓습니다. AI 도면이 여는 파일은 .ttukcad, DXF, STL, OBJ, 3MF, GLB, PLY입니다.
- .ttukcad가 아닌 파일은 그 파일 이름을 딴 새 "제목 없는" 도면으로 열립니다. 원래 파일은 절대 바뀌지 않습니다. 저장하면 언제나 새 .ttukcad 파일을 물어봅니다.
- DWG, STEP, IGES, BREP 파일은 전문 CAD 프로그램이 만든 파일이라 읽지 못합니다. 대신 **이 파일을 여는 방법** 안내가 뜹니다. 보낸 사람에게 DXF(2D 도면)나 STL(3D 모형)로 다시 저장해 달라고 하세요.
- 100MB가 넘는 파일, 삼각형이 200만 개를 넘는 모형은 열리지 않습니다.

## 도형 놓기, 손잡이, 속성 창

- **홈 › 도형 놓기**에 자주 쓰는 도형 4개가 있고, **더 보기**를 누르면 15종 전체가 나옵니다: 상자, 원기둥, 공, 원뿔, 사각뿔, 쐐기, 반구, 관, 도넛, 삼각 기둥, 육각 기둥, 둥근 상자, 별 기둥, 지붕, 글자.
- 새 도형은 작업판(모형이 서는 바닥 판) 한가운데에 나타납니다. 도형을 누르면 선택되고, Shift나 Ctrl을 누른 채 누르면 선택에 더해집니다.
- **보기 › 손잡이**에서 선택한 도형의 손잡이가 할 일을 고릅니다: **옮기기**, **돌리기**, **크기**. 끌면 1mm와 15° 단위로 달라붙고, 끄는 동안 Alt를 누르고 있으면 달라붙지 않습니다.
- 오른쪽 **속성** 창에 선택한 도형의 이름, 종류(채움 또는 구멍), 치수, 위치(mm), 회전(°), 색이 나옵니다. 숫자를 입력해 바꿉니다. **숨기기**와 **잠그기**로 방해되는 도형을 비켜 둘 수 있습니다.
- **보기 › 보는 방향**에서 **위**, **앞**, **옆**으로 카메라를 돌리고, **전체 보기**로 모형 전체를 화면에 맞춥니다. 화면을 끌면 돌아가고, 마우스 휠로 확대·축소합니다.
- 아래 상태 줄에 작업판 크기, 달라붙기와 격자 간격, 선택한 도형의 가로 × 세로 × 높이가 나옵니다.

## 구멍 뚫기, 묶기, 줄 맞추기

- 구멍은 깎아 내는 도형입니다. 도형을 선택하고 **구멍**(또는 H)을 누르면 구멍이 되고, 다시 누르면 채움으로 돌아옵니다.
- 구멍은 묶음 안에서만 뚫립니다. 구멍과 그 구멍이 뚫을 도형을 함께 선택하고 **묶기**(Ctrl+G)를 누르면, 묶음은 채움 도형에서 구멍을 뺀 모양이 됩니다. **풀기**(Ctrl+Shift+G)로 다시 나눕니다.
- **줄 맞추기**는 선택한 도형들을 맨 처음 선택한 도형에 맞춰 줄을 세웁니다: 왼쪽·가운데·오른쪽, 앞·가운데·뒤, 아래·가운데·위.
- 예를 들어 지름 80mm 원기둥과, 5mm 띄워 올린 지름 68mm 구멍 원기둥을 함께 선택해 묶으면 바닥 두께 5mm인 컵이 됩니다.

## 직접 그리기와 글자

- **직접 그리기**로 원하는 모양의 밑그림을 그립니다. 작업판을 눌러 점을 3개 이상 찍고, **점 되돌리기**로 마지막 점을 지웁니다.
- **높이(mm)**를 넣고 **도형 닫기**를 누르면 밑그림이 그 높이로 서서 입체가 됩니다. **취소**를 누르면 아무것도 만들지 않고 나옵니다.
- 선끼리 엇갈리는 밑그림은 받지 않습니다. 엇갈리지 않을 때까지 점을 되돌리세요.
- **글자**는 넣을 글자를 물은 뒤, GenOffice에 든 글꼴로 글자 모양 입체를 만듭니다.

## 치수 재기와 치수 도면

- **치수 재기**는 누른 두 점 사이의 거리, 선의 길이, 원의 지름을 보여 줍니다. 점은 꼭짓점, 선 끝, 원 중심에 달라붙습니다. Esc를 누르면 잰 값이 지워집니다.
- **치수 도면**은 모형을 앞·위·옆 세 방향에서 그린 A4 도면입니다. 전체 가로·세로·높이 치수, 알맞은 축척(1:1, 1:2, 1:5, 1:10 …), 이름·날짜·축척을 적은 표제란이 들어갑니다. DXF 파일에서 온 도면은 위에서 본 그림 하나만 그립니다.
- 치수 도면 창의 **그림 복사**를 누르면 도면이 클립보드에 들어갑니다. 한글, 워드, PPT 탭에 붙여 넣으세요.
- **한글로 보내기**는 도면 그림과 도형별 이름·치수 표가 든 새 한글 문서를 엽니다. 설정에서 **한국 문서 기능**이 꺼져 있으면 단추 이름이 **워드로 보내기**로 바뀌고 워드 문서를 만듭니다.

## AI 도우미에게 말로 시키기

- 도면 옆 AI 창은 도형 놓기, 치수·위치 바꾸기, 구멍 뚫기, 묶기, 줄 맞추기, 작업판 크기 정하기, 모형 요약을 합니다. 이렇게 말해 보세요.
  - "가로 80mm, 높이 100mm 연필꽂이를 만들어 줘. 안은 지름 68mm로 비워 줘"
  - "작업판을 5 × 4m 방으로 만들고 책상 네 개를 놓아 줘"
  - "선택한 도형들을 왼쪽으로 맞춰 줘"
- 요청 하나가 바꾼 것은 도형을 몇 개 건드렸든 **되돌리기**(Ctrl+Z) 한 번으로 모두 돌아갑니다.
- AI가 받는 것은 요청과 모형 요약(도형마다 이름, 종류, 치수, 위치)입니다. AI는 저장, 열기, 내보내기, 보내기를 하지 못합니다. 그 일은 사용자가 합니다.

## 저장, 자동 저장, 복구

- **저장**(Ctrl+S)은 .ttukcad 파일로 씁니다. AI 도면은 이 형식으로만 저장하고, **다른 이름으로 저장…**(Ctrl+Shift+S)으로 새 이름이나 위치를 고릅니다.
- 위쪽의 **자동 저장**을 켜면, 파일로 한 번 저장한 도면을 30초마다와 창이 뒤로 갈 때 저장합니다.
- GenOffice가 갑자기 꺼지면, 다음에 켤 때 **저장하지 않은 내용이 남아 있는 문서** 목록에 도면이 나옵니다. **되살리기**를 누르면 돌아옵니다.

## 내보내기(STL, OBJ, PNG)

- **파일 › STL로 내보내기**와 **OBJ로 내보내기**는 3D 프린터나 다른 프로그램에서 쓸 모형 파일을 만듭니다. **그림(PNG)으로 내보내기**는 지금 보이는 화면을 밝은 바탕 그림으로 저장합니다.
- 내보내기는 도면을 불러온 원래 파일을 덮어쓰지 않습니다.

## AI 도면 단축키

| 키                       | 하는 일                  |
| ------------------------ | ------------------------ |
| Ctrl+Z                   | 되돌리기                 |
| Ctrl+Y 또는 Ctrl+Shift+Z | 다시 하기                |
| Ctrl+S                   | 저장                     |
| Ctrl+A                   | 모두 고르기              |
| Delete                   | 지우기                   |
| Ctrl+D                   | 복제                     |
| Ctrl+G                   | 묶기                     |
| Ctrl+Shift+G             | 풀기                     |
| H                        | 구멍 ↔ 채움              |
| 화살표 키                | 1mm 옮기기(Shift는 10mm) |
| 끄는 동안 Alt            | 달라붙기 끄기            |

탭 안의 **도움말 › 단축키**에도 같은 목록이 있습니다.

## AI 도면이 하지 못하는 것

- DWG, STEP, IGES, BREP 파일을 바로 열기. DXF나 STL로 받아 달라고 하세요.
- 전문 CAD 프로그램의 구속 조건, 설계 이력, 조립. 도형마다 자기 숫자로만 정해집니다.
- 인쇄. 치수 도면을 한글이나 워드 문서로 보내서 거기서 인쇄하세요.
