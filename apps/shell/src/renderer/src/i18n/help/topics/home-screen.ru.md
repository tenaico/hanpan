# Главный экран: где хранятся ваши файлы

Главная — стартовая страница GenOffice: слева боковая панель навигации, справа доска из карточек. Введите тему в карточке **Начало**, чтобы открыть интеллект-карту, а недавние документы открывайте из карточки **Продолжить**; её кнопка **Всего: N** ведёт к полному списку **Недавние**. На экранах на корейском есть ещё карточка с сегодняшним прогнозом Trend Radar; щелчок по области открывает Trend Radar в браузере.

## Навигация на боковой панели

- **Главная**: доска из карточек. Приложение открывается здесь.
- **Недавние**: файлы, которые вы открывали недавно. В каждой строке проставлено время — сегодня, вчера или дата.
- **Избранное**: файлы, которым вы поставили звёздочку. Наведите курсор на строку файла и нажмите на звёздочку, чтобы добавить или убрать. **Переместить в группу** в меню ⋯ раскладывает файлы со звёздочкой по именованным группам; вид «Со звёздочкой» фильтруется по ним.
- **Руководство пользователя**: открывает это руководство.
- **Ask AI**: панель базы знаний — задавайте вопросы и получайте ответы со ссылками на файлы со звёздочкой (см. ниже).
- **Папки**: каталоги, которые вы добавляете на боковую панель кнопкой **Добавить папку…** или перетаскиваете туда из файлового менеджера. Каждый становится корнем, который можно открыть, создать в нём подпапки, переименовать и удалить; тот, что стал недоступен, показывается как недоступный, и его можно убрать из списка. **Новая папка** создаёт ещё одну.
- **Строка внизу**: показывает, подключён ли ИИ, — **Подключить ИИ** или название подключённой подписки — и открывает настройки.

Здесь нет пункта Корзина. Удалённые файлы попадают в системную корзину, а восстановить их — дело ОС.

## Список файлов

В каждой строке показаны значок, имя файла, время изменения и прочее. **Меню ⋯** строки предлагает:

- **Открыть**, а также **Показать в папке**, чтобы найти файл в файловом менеджере.
- **Скопировать путь**.
- **Переместить в папку…**: открывает выбор папки и действительно перемещает файл; если в месте назначения уже есть файл с таким именем, можно пропустить, перезаписать или переименовать.
- **Переименовать**: прямо на месте, расширение сохраняется автоматически.
- **В избранное / Убрать из избранного** — звёздочки сохраняются после перезапуска и следуют за файлом, когда вы его переименовываете.
- **Создать копию**: создаёт копию в той же папке.
- **Удалить**: перемещает файл в системную корзину — это не безвозвратное удаление.
- **Убрать из списка**, в основном представлении **Недавние**, чтобы убрать запись, не трогая сам файл.

### Сразу несколько файлов

Поставьте флажок у строки или щёлкните с ⌘/ctrl, чтобы собрать выделение; флажок в заголовке выбирает всё, что сейчас перечислено, а полоса над списком сообщает (**Выбрано: {n}**), сколько выбрано, и предлагает **Переместить в папку…** и **Удалить файлы** для всего набора. Множественное выделение можно также перетащить на папку в боковой панели.

## Поиск

Введите запрос в поле поиска в верхней строке доски — результаты появятся на месте доски; очистите поиск или нажмите Esc, чтобы вернуться к доске. Поиск идёт сразу по двум направлениям:

- **Имена файлов**: быстрая фильтрация по имени.
- **Содержимое файлов**: GenOffice индексирует ваши файлы в фоне (текст внутри docx/odt/xlsx/pptx/pdf/md/html), поэтому поиск по тексту документа тоже находит файлы. Область поиска и переключатели заданы в настройках поиска.

## Настроить главную

Нажмите **Настроить главную** справа в верхней строке доски, чтобы изменить карточки. Изменения сохраняются сразу; закончив, нажмите **Готово** или Esc.

- Перетащите карточку, чтобы переместить её, или её правый нижний угол, чтобы изменить размер; размер можно выбрать и в меню карточки **⋯**. В карточке **Создать** перетаскивайте приложения, чтобы изменить порядок, или нажмите ×, чтобы убрать приложение с главной.
- **Добавить карточку** добавляет быструю заметку, избранное, просмотр папки, часы или ярлык и возвращает убранные карточки. На главной помещается до 24 карточек.
- **Расположение по умолчанию** возвращает исходный порядок и размер стандартных карточек и приложения на главной. Добавленные вами карточки останутся.
- **Упорядочить списком** показывает карточки и приложения в виде списка, где их можно без мыши переставлять клавишами ↑↓, добавлять, убирать и выбирать размер.

## Создать и Все приложения

В карточке **Создать** — приложения, закреплённые на главной. Щелчок по приложению создаёт файл этого типа и открывает его редактор — начните писать сразу или поручите черновик ИИ (в каждом редакторе есть **кнопка AI** на ленте и **Спросить ИИ** в контекстном меню выделения). Последняя ячейка, **Все приложения**, показывает все приложения по группам: ищите по названию или назначению, откройте одно из трёх **Недавние приложения** или кнопкой закрепления закрепите приложение на главной либо уберите его. Приложения, появившиеся в новой версии, отмечены значком **Новое**.

Новый файл попадает в папку, выбранную сейчас на боковой панели; если ничего не выбрано, он попадает в папку по умолчанию.

Что делает каждое приложение:

- **AI Docs** (.docx): пустой текстовый документ в редакторе Docs. Файл записывается на диск только при **первом сохранении**; новые документы открываются с развёрнутой панелью ИИ (это отключается в Настройки → «Открывать панель ИИ в новых документах»).
- **AI Sheets** (.xlsx): пустая таблица в редакторе Sheets. До первого сохранения файла на диске нет — имя зарезервировано для первого сохранения; после первой генерации ИИ файл также может быть переименован автоматически по содержимому.
- **AI Slides** (.pptx): пустая презентация в редакторе Slides.
- **AI Markdown** (.md): пустой документ Markdown в редакторе Markdown.
- **AI HTML** (.html): пустая веб-страница в редакторе HTML.
- **AI PDF** (.pdf): отличается от остальных — она **сразу** создаёт настоящий пустой одностраничный PDF в целевой папке и открывает его как обычный файл (редактор PDF работает с настоящими файлами). Подходит для аннотирования, сокрытия данных и добавления текста; при первом сохранении файл можно переименовать автоматически по содержимому.
- **Открыть локальный файл**: системный выбор файлов для Word (.docx/.doc/.odt), Excel (.xlsx/.xlsm/.xls/.csv/.tsv), PowerPoint (.pptx/.ppt), PDF, Markdown (.md/.markdown) и веб-страниц (.html/.htm). Можно выбрать несколько файлов сразу; каждому файлу достаётся своя вкладка. Текстовые файлы (.txt, .json) тоже открываются отсюда — они попадают в режим исходника редактора Markdown.

> Совет: меню Файл ▸ Создать на панели меню создаёт те же типы документов (⌘N/Ctrl+N по умолчанию создаёт текстовый документ); перетаскивание файла в окно открывает его.

## Спросите свою базу знаний

- Сначала отметьте файлы звёздочкой (любой читаемый приложением тип); в шапке панели указан размер корпуса, а пустая база предложит сначала что-нибудь отметить.
- Ответы называют файлы-источники; щелчок по ссылке открывает файл в его редакторе.
- Нужен подключённый ИИ; см. [Подключение по подписке](help://subscription). Разговор живёт только в памяти — закрытие приложения его завершает.
- Поиск идёт по локальному индексу файлов, как на «Главной»; исчезнувшие файлы тихо выпадают из корпуса.
- Группы нужны только для списка «Со звёздочкой» — база знаний всегда охватывает все файлы со звёздочкой.
