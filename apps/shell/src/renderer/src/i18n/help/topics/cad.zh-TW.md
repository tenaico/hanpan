# AI 圖面

AI 圖面是用來處理簡單 3D 模型和圖面的分頁。你可以開啟別人寄來的圖面檢查尺寸，自己動手或請 AI 幫忙做一個小模型，再把尺寸圖放進 Hangul 或 Word 文件。圖面會儲存成 .ttukcad 檔案，所有長度都以公釐為單位。

## 開啟圖面

- 新增圖面：在首頁開啟 **所有應用程式**，按 **AI 圖面**。分頁一開始的名稱是 **未命名圖紙**。
- 開啟檔案：使用 **檔案 › 開啟…**（Ctrl+O），或把檔案拖到視窗上。AI 圖面可以開啟 .ttukcad、DXF、STL、OBJ、3MF、GLB 和 PLY 檔案。
- 不是 .ttukcad 的檔案，會以該檔名開啟成一張新的未命名圖面。原始檔案絕不會被修改：儲存時一律會要求另存成新的 .ttukcad 檔案。
- DWG、STEP、IGES 和 BREP 檔案來自專業 CAD 軟體，無法讀取。這時會顯示 **如何開啟此檔案**：請寄件人改寄 DXF（2D 圖面）或 STL（3D 模型）。
- 超過 100 MB 的檔案，或三角形超過 200 萬個的模型，無法開啟。

## 放置形狀

- **常用 › 放置形狀** 裡有最常用的 4 種形狀；按 **更多** 可以開啟全部 15 種：長方體、圓柱、球、圓錐、四角錐、楔形、半球、圓管、圓環、三角柱、六角柱、圓角長方體、星形柱、屋頂和文字。
- 新形狀會出現在工作板的正中央，工作板就是模型站立的底板。按一下某個零件即可選取；按住 Shift 或 Ctrl 再按，可以把更多零件加入選取。
- **檢視 › 控點** 決定選取零件上的控點要做什麼：**移動**、**旋轉** 或 **大小**。拖曳時會以 1 mm 和 15° 為單位貼齊；拖曳時按住 Alt 可以關閉貼齊。
- 右側的 **屬性** 窗格會顯示選取零件的名稱、類型（實體或孔）、尺寸、位置（mm）、旋轉（°）和顏色。輸入數字就能修改。**隱藏** 和 **鎖定** 可以讓零件不礙事。
- **檢視 › 視角** 可以把鏡頭轉到 **俯視**、**前視** 或 **側視**，**全部顯示** 會讓整個模型完整出現在畫面上。在檢視畫面中拖曳可以旋轉，捲動滑鼠滾輪可以縮放。
- 底部的狀態列會顯示工作板大小、貼齊間距和格線間距，以及選取零件的寬 × 深 × 高。

## 孔、群組與對齊

- 孔是用來挖空的形狀。選取一個形狀後按 **孔**（或按 H）就會變成孔；再按一次就變回實體。
- 孔只在群組內才有作用。同時選取孔和要被挖空的實體，再按 **群組**（Ctrl+G）：群組的結果就是實體減去孔。**取消群組**（Ctrl+Shift+G）可以把它拆開。
- **對齊** 會讓選取的零件以第一個選取的零件為基準排整齊：左、中、右；前、中、後；底、中、頂。
- 舉例來說：一個直徑 80 mm 的圓柱，加上一個直徑 68 mm、往上墊高 5 mm 的孔圓柱，兩者一起選取並組成群組，就成了一個杯底厚 5 mm 的杯子。

## 自由繪製與文字

- **自由繪製** 用來畫出你自己的輪廓。在工作板上按一下，至少放 3 個點；**復原點** 會取消最後一個點。
- 輸入 **高度（公釐）**，再按 **封閉形狀**：輪廓就會立起來變成實體。**取消** 會直接離開，不產生任何東西。
- 彼此交叉的線條無法使用。請持續復原點，直到線條不再交叉。
- **文字** 會詢問要放置的文字內容，並用 GenOffice 內附的字型把它變成立體文字。

## 測量與尺寸圖

- **測量** 會顯示你點選的兩點之間的距離、一條線的長度或一個圓的直徑。點會自動貼齊角點、線段端點和圓心。按 Esc 清除測量結果。
- **尺寸圖** 會在一張 A4 紙上從正面、上面和側面畫出模型，標出總寬、總深和總高，自動選用合適的比例（1:1、1:2、1:5、1:10 …），並附上寫有名稱、日期和比例的標題欄。來自 DXF 檔案的圖面只會顯示俯視圖。
- 在尺寸圖中按 **複製圖片**，就會把它放到剪貼簿，接著可以貼到 Hangul、Word 或 PowerPoint 分頁裡。
- **傳送到 Hangul** 會開啟一份新的 Hangul 文件，裡面有尺寸圖，以及一張列出各零件和尺寸的表格。如果在設定中關閉了 **韓國文件功能**，按鈕會變成 **傳送到 Word**，改為產生 Word 文件。

## AI 助理

- 圖面旁邊的 AI 窗格可以放置形狀、修改尺寸和位置、做孔、組成群組、對齊、設定工作板大小，並摘要整個模型。可以試試這些要求：
  - 「做一個寬 80 mm、高 100 mm 的筆筒，裡面挖空，內徑 68 mm」
  - 「把工作板設成 5 × 4 m 的房間，並放四張辦公桌」
  - 「把選取的零件靠左對齊」
- 一次要求所改動的全部內容，不論動到多少個零件，都能用一次 **復原**（Ctrl+Z）全部撤回。
- AI 會收到你的要求和模型摘要（每個零件的名稱、類型、尺寸和位置）。它不能儲存、開啟、匯出或傳送；這些動作都要由你自己來做。

## 儲存與還原

- **儲存**（Ctrl+S）會寫入 .ttukcad 檔案。AI 圖面只能儲存成這種格式；**另存新檔…**（Ctrl+Shift+S）可以換一個名稱或位置。
- 圖面有了自己的檔案之後，上方的 **自動儲存** 會每 30 秒儲存一次，視窗失去焦點時也會儲存。
- 如果 GenOffice 意外關閉，下次啟動時這張圖面會列在 **有未儲存內容的文件** 中。按 **還原** 就能找回來。

## 匯出

- **檔案 › 匯出 STL** 和 **匯出 OBJ** 會把模型寫成檔案，給 3D 印表機或其他軟體使用。**匯出圖片 (PNG)** 會以淺色背景儲存目前畫面顯示的內容。
- 匯出絕不會覆寫圖面原本的來源檔案。

## 快速鍵

| 按鍵                   | 功能                               |
| ---------------------- | ---------------------------------- |
| Ctrl+Z                 | 復原                               |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做                               |
| Ctrl+S                 | 儲存                               |
| Ctrl+A                 | 全選                               |
| Delete                 | 刪除                               |
| Ctrl+D                 | 複製一份                           |
| Ctrl+G                 | 群組                               |
| Ctrl+Shift+G           | 取消群組                           |
| H                      | 孔 ↔ 實體                          |
| 方向鍵                 | 移動 1 mm（按住 Shift 移動 10 mm） |
| 拖曳時按住 Alt         | 關閉貼齊                           |

**說明 › 快速鍵** 會在分頁內顯示同樣的清單。

## 做不到的事

- 直接開啟 DWG、STEP、IGES 或 BREP 檔案。請改為索取 DXF 或 STL 檔案。
- 像專業 CAD 軟體那樣的限制條件、設計歷程或組合件。每個零件都由它自己的數值決定。
- 列印。請把尺寸圖傳送到 Hangul 或 Word 文件，再從那裡列印。
