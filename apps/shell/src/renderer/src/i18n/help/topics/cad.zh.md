# AI 图纸

AI 图纸是用来处理简单 3D 模型和图纸的标签页。你可以打开别人发来的图纸查看尺寸，自己动手或让 AI 帮忙做一个小模型，再把尺寸图放进 Hangul 或 Word 文档。图纸保存为 .ttukcad 文件，所有长度都以毫米为单位。

## 打开图纸

- 新建图纸：在主页打开 **所有应用**，点击 **AI 图纸**。标签页一开始的名称是 **未命名图纸**。
- 打开文件：使用 **文件 › 打开…**（Ctrl+O），或把文件拖到窗口上。AI 图纸可以打开 .ttukcad、DXF、DWG、STL、OBJ、3MF、GLB 和 PLY 文件。DWG 支持从 AutoCAD R14 格式到 2018 格式。
- 不是 .ttukcad 的文件会以该文件名打开为一张新的未命名图纸。原文件永远不会被改动：保存时总是会要求另存为新的 .ttukcad 文件。
- STEP、IGES 和 BREP 文件是专业 CAD 软件生成的 3D 文件，无法读取。这时会显示 **如何打开此文件**：请发件人改发 STL（3D 模型）。
- 超过 100 MB 的文件，或三角形超过 200 万个的模型，无法打开。

## 放置形状

- **开始 › 放置形状** 里有最常用的 4 种形状；点击 **更多** 可以打开全部 15 种：长方体、圆柱、球、圆锥、四棱锥、楔形、半球、圆管、圆环、三棱柱、六棱柱、圆角长方体、星形柱、屋顶和文字。
- 新形状出现在工作板的正中央，工作板就是模型所站的底板。点击某个形状即可选中；按住 Shift 或 Ctrl 再点击，可以把更多形状加入选择。
- **视图 › 手柄** 决定选中形状上的手柄用来做什么：**移动**、**旋转** 或 **大小**。拖动时会按 1 mm 和 15° 吸附；拖动时按住 Alt 可以关闭吸附。
- 右侧的 **属性** 面板显示选中形状的名称、类型（实体或孔）、尺寸、位置（mm）、旋转（°）和颜色。输入数字即可修改。**隐藏** 和 **锁定** 可以让某个形状不碍事。
- **视图 › 视角** 可以把镜头转到 **俯视**、**前视** 或 **侧视**，**全部显示** 会让整个模型完整出现在画面中。在视图中拖动可以旋转，滚动鼠标滚轮可以缩放。
- 底部的状态栏显示工作板大小、吸附间距和网格间距，以及选中形状的宽 × 深 × 高。

## 孔、组合与对齐

- 孔是用来挖空的形状。选中一个形状后点击 **孔**（或按 H）即可变成孔；再按一次就变回实体。
- 孔只在组合内部起作用。同时选中孔和要被挖空的实体，然后点击 **组合**（Ctrl+G）：组合的结果就是实体减去孔。**取消组合**（Ctrl+Shift+G）可以把它拆开。
- **对齐** 会让选中的形状以最先选中的那个形状为基准排齐：左、中、右；前、中、后；底、中、顶。
- 举个例子：一个直径 80 mm 的圆柱，加上一个直径 68 mm、向上抬高 5 mm 的孔圆柱，两者一起选中并组合，就得到一个杯底厚 5 mm 的杯子。

## 自由绘制与文字

- **自由绘制** 用来画你自己的轮廓。在工作板上点击，至少放 3 个点；**撤销点** 会撤回最后一个点。
- 输入 **高度（毫米）**，再点击 **闭合形状**：轮廓就会立起来变成实体。**取消** 会直接退出，不生成任何东西。
- 互相交叉的线条无法使用。请一直撤销点，直到线条不再交叉。
- **文字** 会询问要放置的文字内容，并用 GenOffice 自带的字体把它变成立体文字。

## 修改收到的图纸中的线条和文字

- 打开 DXF 或 DWG，按 **编辑线条**。点击图纸中的线、圆、圆弧或文字即可选中（会显示为高亮色）；按住 Shift 再点击可以多选。
- 在下方的栏中，**删除**（或 Delete 键）删除所选内容，**移动** 按你输入的 X 和 Y（mm）平移所选内容；只选中一段文字时，输入新的文字后按 **更改文字**。按 Esc 取消选择，再按一次结束编辑线条。
- 每次修改都可以用一次 **撤销**（Ctrl+Z）撤回。已锁定的图纸不会被修改。
- 也可以让 AI 助手来做，例如：“删除尺寸图层上的所有内容”“把文字‘会议室’改成‘大会议室’”“把门图层向右移动 500 mm”。
- 结果保存为 .ttukcad。原来的 DXF 或 DWG 文件永远不会被改动。

## 测量与尺寸图

- **测量** 显示你点击的两点之间的距离、一条线的长度或一个圆的直径。点会自动吸附到角点、线端和圆心。按 Esc 清除测量结果。
- **尺寸图** 在一张 A4 纸上从正面、顶面和侧面画出模型，标出总宽、总深和总高，自动选用合适的比例（1:1、1:2、1:5、1:10 …），并附上写有名称、日期和比例的标题栏。来自 DXF 文件的图纸只显示俯视图。
- 在尺寸图中，**复制图片** 会把它放到剪贴板上，然后可以粘贴到 Hangul、Word 或 PowerPoint 标签页里。
- **发送到 Hangul** 会新建一个 Hangul 文档，里面有尺寸图和一张列出各形状及其尺寸的表格。如果在设置中关闭了 **韩国文档功能**，按钮会显示为 **发送到 Word**，改为生成 Word 文档。

## AI 助手

- 图纸旁边的 AI 面板可以放置形状、修改尺寸和位置、做孔、组合、对齐、设置工作板大小，并概括整个模型。可以试试这些请求：
  - “做一个宽 80 mm、高 100 mm 的笔筒，里面挖空，内径 68 mm”
  - “把工作板设成 5 × 4 m 的房间，并放四张书桌”
  - “把选中的形状向左对齐”
- 一次请求改动的所有内容，不管涉及多少个形状，都可以用一次 **撤销**（Ctrl+Z）全部撤回。
- AI 会收到你的请求和模型摘要（每个形状的名称、类型、尺寸和位置）。它不能保存、打开、导出或发送；这些操作都由你自己来做。
- 要给 AI 一份规格说明或草图，可用输入框下方的回形针按钮附加、拖到面板上，或粘贴图片（Ctrl+V）。AI 会读取并照着建模；文件不会进入图纸，这个请求仍然只需撤销一次。

## 保存与恢复

- **保存**（Ctrl+S）会写入 .ttukcad 文件。AI 图纸只能保存为这种格式；**另存为…**（Ctrl+Shift+S）可以换一个名称或位置。
- 图纸有了自己的文件后，顶部的 **自动保存** 会每 30 秒保存一次，窗口失去焦点时也会保存。
- 如果 GenOffice 意外关闭，下次启动时这张图纸会出现在 **有未保存内容的文档** 中。点击 **恢复** 即可找回。

## 导出

- **文件 › 导出 STL** 和 **导出 OBJ** 会把模型写成文件，供 3D 打印机或其他软件使用。**导出图片 (PNG)** 会以浅色背景保存当前视图中显示的内容。
- 导出永远不会覆盖图纸的来源文件。

## 快捷键

| 按键                   | 作用                               |
| ---------------------- | ---------------------------------- |
| Ctrl+Z                 | 撤销                               |
| Ctrl+Y 或 Ctrl+Shift+Z | 重做                               |
| Ctrl+S                 | 保存                               |
| Ctrl+A                 | 全选                               |
| Delete                 | 删除                               |
| Ctrl+D                 | 复制一份                           |
| Ctrl+G                 | 组合                               |
| Ctrl+Shift+G           | 取消组合                           |
| H                      | 孔 ↔ 实体                          |
| 方向键                 | 移动 1 mm（按住 Shift 移动 10 mm） |
| 拖动时按住 Alt         | 关闭吸附                           |

**帮助 › 快捷键** 会在标签页内显示同样的列表。

## 无法做到的事

- 直接打开 STEP、IGES 或 BREP 文件。请改为索取 STL 文件。
- 保存回 DXF 或 DWG。修改后的图纸保存为 .ttukcad。
- 像专业 CAD 软件那样的约束、设计历史或装配。每个形状都由它自己的数值决定。
- 打印。请把尺寸图发送到 Hangul 或 Word 文档，再从那里打印。
