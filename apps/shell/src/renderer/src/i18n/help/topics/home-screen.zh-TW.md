# 首頁（Home）：檔案都在哪裡

首頁是 GenOffice 的起始頁：左側是導覽側邊欄，右側是由卡片組成的看板。在 **開始** 卡片中輸入主題即可開啟心智圖，在 **繼續工作** 卡片中可以重新開啟最近的文件；按卡片上的 **全部 N 個** 會前往完整的 **最近** 清單。韓文介面中還有一張卡片顯示 Trend Radar 的今日預報，按某個領域會在瀏覽器中開啟 Trend Radar。

## 側邊欄導覽

- **首頁**：開啟卡片看板。啟動應用程式後從這裡開始。
- **最近**：你最近開啟過的檔案。每一列都標著時間——今天、昨天或日期。
- **收藏**：你加過星號的檔案。將滑鼠停在檔案列上，按一下星號即可加入或移除。 **⋯ 選單**裡的 **移至群組** 可把收藏歸入命名群組；收藏檢視按群組篩選。
- **使用手冊**：開啟本手冊。
- **AI 問答**：知識庫面板——就收藏的檔案提問，回答附出處（見下文）。
- **資料夾**：用「加入資料夾…」加到側邊欄，或從檔案總管拖進來的目錄。每一個都會成為一個根目錄，可以開啟、在其中建立子資料夾、重新命名與移除；離線的根目錄會顯示為「無法使用」，也可從清單中移除。「新增資料夾」可以再建立一個。
- **最底下的那一列**：顯示 AI 是否已經連線——**連結 AI**，或是已連線訂閱的名稱——按一下可開啟設定。

這裡沒有「垃圾桶」項目。刪除的檔案都會進入系統垃圾桶，如何還原是作業系統的事。

## 檔案清單

每一列會顯示圖示、檔案名稱、修改時間等資訊。該列的 **⋯ 選單** 提供：

- **開啟**，以及** 開啟所在資料夾**，在檔案總管中找出這個檔案。
- **複製路徑**。
- **移至資料夾…**：開啟資料夾選取器並真正移動檔案；當目的地已有同名檔案時，可以選擇略過、覆寫或重新命名。
- **重新命名**：就地改名（副檔名會自動保留）。
- **收藏／取消收藏** — 星號在重新啟動後依然保留，改名後也會跟著檔案走。
- **建立副本**：在同一個資料夾中建立一份副本。
- **刪除**：將檔案移到系統垃圾桶，並非永久刪除。
- **從清單中移除**，在頂層的「最近」檢視中，只移除這個項目而不動檔案本身。

### 一次處理多個檔案

勾選某一列的核取方塊，或按住 ⌘/ctrl 點選，即可建立選取範圍；標題列的核取方塊會全選目前列出來的項目，列表上方的工具列會顯示已選取的數量（**已選 {n} 項**），並為整組提供** 移至資料夾…**與** 刪除檔案**。多選之後也可以直接拖到側邊欄的某個資料夾上。

## 搜尋

在看板最上面一列的搜尋框中輸入內容，結果會顯示在看板的位置；清除搜尋或按 Esc 即可回到看板。搜尋會同時找兩類內容：

- **檔案名稱**：依名稱快速篩選。
- **檔案內容**：GenOffice 會在背景為你的檔案建立索引（docx/odt/xlsx/pptx/pdf/md/html 內的文字），所以搜尋內文也找得到檔案。搜尋範圍與開關可在搜尋設定中調整。

## 自訂首頁

按看板最上面一列右側的 **自訂首頁** 即可調整卡片。變更會立即儲存，完成後按 **完成** 或 Esc。

- 拖曳卡片即可移動，拖曳右下角即可調整大小；也可以在卡片的 **⋯** 選單中選擇大小。在 **新增** 卡片中可以拖曳應用程式來調整順序，按 × 可將其從首頁移除。
- 用 **新增卡片** 可以加入快速便箋、我的最愛、資料夾檢視、時鐘與日期、捷徑卡片，移除過的卡片也在這裡重新加入。首頁最多可放 24 張卡片。
- **恢復預設版面** 會將預設卡片的順序與大小，以及首頁上顯示的應用程式恢復為初始狀態。自行新增的卡片會保留。
- **整理成清單** 會在清單視窗中顯示卡片和應用程式，不用滑鼠也能用 ↑↓ 調整順序、加入或移除、選擇大小。

## 新增與所有應用程式

**新增** 卡片中放著你釘選到首頁的應用程式。按一個應用程式就會建立該類型的檔案並開啟對應的編輯器，可以直接開始寫，也可以讓 AI 起草（每個編輯器的功能區都有 **AI 按鈕**，選取內容後的右鍵選單也有 **問 AI**）。最後一格 **所有應用程式** 會依分組列出全部應用程式：可以依名稱或用途搜尋，從 **最近使用的應用程式** 直接開啟最近用過的 3 個，也可以用每個應用程式的釘選按鈕將它釘選到首頁或從首頁移除。新版本中新增的應用程式會帶有 **新** 標記。

新檔案會存放在側邊欄目前選取的資料夾；沒有選取時則存入預設資料夾。

各應用程式的作用：

- **AI Docs**（.docx）：在 Docs 編輯器中開啟一份空白文字文件。檔案要到** 第一次儲存**時才真正寫入磁碟；新文件預設會展開 AI 面板，不需要時可在 設定 →「在新文件中開啟 AI 面板」關掉。
- **AI Sheets**（.xlsx）：在 Sheets 編輯器中開啟一份空白試算表。在你儲存之前，磁碟上其實還沒有這個檔案——檔名是先替第一次儲存保留的；首次由 AI 產生內容後，檔名還可以依內容自動更改。
- **AI Slides**（.pptx）：在 Slides 編輯器中開啟一份空白簡報。
- **AI Markdown**（.md）：在 Markdown 編輯器中開啟一份空白 Markdown 文件。
- **AI HTML**（.html）：在 HTML 編輯器中開啟一份空白網頁。
- **AI PDF**（.pdf）：與其他卡片不同——它會在目標資料夾中** 立即**建立一個真正的空白單頁 PDF，並以一般檔案的方式開啟（PDF 編輯器處理的是真實檔案）。適合用來加註解、塗黑或加入文字；檔名在第一次儲存時可依內容自動更改。
- **開啟本機檔案**：開啟系統檔案選擇視窗，支援 Word（.docx/.doc/.odt）、Excel（.xlsx/.xlsm/.xls/.csv/.tsv）、PowerPoint（.pptx/.ppt）、PDF、Markdown（.md/.markdown）與網頁（.html/.htm）。可複選；每個檔案各自開一個分頁。 純文字檔案（.txt、.json）也可以在這裡開啟——會直接進入 Markdown 編輯器的原始碼檢視。

> 提示：選單列的 檔案 ▸ 新增 也能建立相同類型的文件（⌘N/Ctrl+N 預設建立文字文件）；把檔案直接拖進視窗等同於開啟它。

## 問知識庫

- 先收藏檔案（應用程式能讀的類型都行）；面板標題顯示庫的大小，空庫會提示先去加星。
- 回答會標明出處檔案；點引用即在對應編輯器裡開啟該檔案。
- 需要已連線的 AI，請見[訂閱連線](help://subscription)。對談只存在記憶體裡——關閉應用程式即結束。
- 檢索走本機檔案索引（與首頁搜尋相同）；已不存在的檔案會自動移出語料。
- 群組只用於整理收藏清單——知識庫永遠涵蓋全部收藏檔案。
