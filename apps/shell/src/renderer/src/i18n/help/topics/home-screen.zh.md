# 主屏（Home）：文件都在哪

主页是 GenOffice 的起始页：左侧是导航侧栏，右侧是由卡片组成的看板。在 **开始** 卡片中输入主题即可打开思维导图，在 **继续工作** 卡片中可以重新打开最近的文档；点卡片上的 **全部 N 个** 会转到完整的 **最近** 列表。韩语界面中还有一张卡片显示 Trend Radar 的今日预报，点某个领域会在浏览器中打开 Trend Radar。

## 侧栏导航

- **主页**：打开卡片看板。启动应用后从这里开始。
- **最近**：最近打开过的文件。每一行都标着时间——今天、昨天或具体日期。
- **收藏**：你标过星的文件。把鼠标悬停在文件行上点星标即可加入或移出。 **⋯ 菜单**里的 **移动到分组** 可把收藏归入命名分组；收藏视图按分组筛选。
- **使用手册**：打开本手册。
- **AI 问答**：知识库面板——就收藏的文件提问，回答带引用（见下文）。
- **文件夹**：用「添加文件夹…」加入侧栏，或从文件管理器拖进来的目录。每一个都会成为一个根目录，可以打开、在其中新建子文件夹、重命名和移除；离线的根目录显示为「不可用」，也可以从列表中移除。「新建文件夹」可以再建一个。
- **最底下的那一行**：显示 AI 是否已连接——**连接 AI**，或已连接订阅的名称——点它可打开设置。

这里没有「回收站」入口。删除的文件都进了系统废纸篓，怎么还原是操作系统的事。

## 文件列表

每一行显示图标、文件名、修改时间等信息。行上的 **⋯ 菜单** 提供：

- **打开**，以及** 打开所在文件夹**，在系统文件管理器里定位该文件。
- **复制路径**。
- **移动到文件夹…**：打开文件夹选择器并真正移动文件；当目标位置已有同名文件时，可选择跳过、覆盖或重命名。
- **重命名**：就地改名（扩展名自动保留）。
- **收藏 / 取消收藏** — 星标在重启后依然保留，改名后也跟着文件走。
- **创建副本**：在同一目录中创建一份副本。
- **删除**：移入系统废纸篓，不是永久删除。
- **从列表中移除**，在顶层的「最近」视图中，只去掉这一条而不动文件本身。

### 一次处理多个文件

勾选某一行的复选框，或按住 ⌘/ctrl 点击，即可建立选择；表头的复选框全选当前列出的所有项，列表上方的工具条会显示已选数量（**已选 {n} 项**），并为整组提供** 移动到文件夹…**和** 删除文件**。多选之后也可以直接拖到侧栏的某个文件夹上。

## 搜索

在看板最上面一行的搜索框中输入内容，结果会显示在看板的位置；清空搜索或按 Esc 即可回到看板。搜索同时查找两类内容：

- **文件名**：按名称快速过滤。
- **文件内容**：GenOffice 会在后台给文件建索引（docx/odt/xlsx/pptx/pdf/md/html 的文字），所以搜正文也能找到文件。搜索设置里可以调整范围与开关。

## 自定义主页

点看板最上面一行右侧的 **自定义主页** 即可调整卡片。更改会立即保存，完成后点 **完成** 或按 Esc。

- 拖动卡片可以移动它，拖动右下角可以调整大小；也可以在卡片的 **⋯** 菜单中选择大小。在 **新建** 卡片中可以拖动应用来调整顺序，点 × 可将其从主页移除。
- 用 **添加卡片** 可以添加快速便笺、收藏、文件夹视图、时钟与日期、快捷方式卡片，移除过的卡片也在这里重新添加。主页最多可放 24 张卡片。
- **恢复默认布局** 会把默认卡片的顺序和大小，以及主页上显示的应用恢复为初始状态。自己添加的卡片会保留。
- **按列表整理** 会在列表窗口中显示卡片和应用，不用鼠标也能用 ↑↓ 调整顺序、添加或移除、选择大小。

## 新建与所有应用

**新建** 卡片中放着你固定到主页的应用。点一个应用就会创建该类型的文件并打开对应的编辑器，可以直接开始写，也可以让 AI 起草（每个编辑器的功能区都有 **AI 按钮**，或选中内容后右键 **问 AI**）。最后一格 **所有应用** 会按分组列出全部应用：可以按应用名称或用途查找，从 **最近使用的应用** 中直接打开最近用过的 3 个应用，也可以用每个应用的固定按钮把它固定到主页或从主页移除。新版本中新增的应用会带有 **新** 标记。

新建的文件会落在侧栏当前选中的文件夹里；没有选中则落在默认文件夹。

各应用的作用：

- **AI Docs**（.docx）：空白文字文档，进入 Docs 编辑器。文件在你** 首次保存时**才真正写入磁盘；新文档默认展开 AI 面板，不需要时可在 设置 → 「AI 面板」中选择「关闭」或「收起」。
- **AI Sheets**（.xlsx）：空白电子表格，进入 Sheets 编辑器。保存之前磁盘上并没有这个文件——文件名预留给首次保存；首次让 AI 生成内容后，文件还可按内容自动改名。
- **AI Slides**（.pptx）：空白演示文稿，进入 Slides 编辑器。
- **AI Markdown**（.md）：空白 Markdown 文档，进入 Markdown 编辑器。
- **AI HTML**（.html）：空白网页文档，进入 HTML 编辑器。
- **AI PDF**（.pdf）：和其他卡片不同——它会** 立即**在目标文件夹创建一个真正的空白单页 PDF，并作为普通文件打开（PDF 编辑器处理的是真实文件）。适合在上面做注释、涂黑、添加文字；首次保存时可按内容自动改名。
- **打开本地文件**：弹出系统文件选择框，支持 Word（.docx/.doc/.odt）、Excel（.xlsx/.xlsm/.xls/.csv/.tsv）、PowerPoint（.pptx/.ppt）、PDF、Markdown（.md/.markdown）和网页（.html/.htm）。可一次选多个文件，每个文件一个标签页。 纯文本文件（.txt、.json）也可以在这里打开——会直接进入 Markdown 编辑器的源码视图。

> 提示：菜单栏 文件 ▸ 新建 也能新建同样类型的文档（⌘N/Ctrl+N 默认新建文字文档）；把文件直接拖进窗口等于打开它。

## 问知识库

- 先收藏文件（应用能读的类型都行）；面板头部显示库的大小，空库会提示先去点星。
- 回答会标明出处文件；点引用即在对应编辑器里打开该文件。
- 需要已连接的 AI，见[订阅连接](help://subscription)。会话只存在内存里——关闭应用即结束。
- 检索走本机文件索引（与主屏搜索相同）；已不存在的文件会自动移出语料。
- 分组只用于整理收藏列表——知识库永远覆盖全部收藏文件。
